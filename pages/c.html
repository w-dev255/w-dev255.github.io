Variable

A variable in C is a named region of memory with a defined type, and can hold only values compatible with that type.

/*int example*/

int name = 1;

/*float example*/

float name = 1.0f;

/*double example*/

double name = 1.00;

/*char example*/

char name = 'C';

/*string example*/

char name[] = "C is the solution";

Pointers

A pointer is a typed variable that stores the memory address of another object, allowing indirect access to that object through dereferencing.

/*int example*/

int name = 1;

int* p = &name;

/*float example*/

float name = 1.0f;

float* p = &name;

/*double example*/

double name = 1.00;

double* p = &name;

/*string example*/

char name[] = "string";

char* p = name;
