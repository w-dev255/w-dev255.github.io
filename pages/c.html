Variable

A variable in C is a named region of memory with a defined type, and can hold only values compatible with that type.

/*int example*/

int name = 1;

/*float example*/

float name = 1.0f;

/*double example*/

double name = 1.00;

/*char example*/

char name = 'C';

/*string example*/

char name[] = "C is the solution";

Pointers

A pointer is a typed variable that stores the memory address of another object, allowing indirect access to that object through dereferencing.

/*int example*/

int name = 1;

int* p = &name;

/*float example*/

float name = 1.0f;

float* p = &name;

/*double example*/

double name = 1.00;

double* p = &name;

/*string example*/

char name[] = "string";

char* p = name;

<stdio.h>

The <stdio.h> library is one of the building blocks that make the C language powerful. Its role is to provide access to various tools designed to manage stdin, stdout, and stderr.

#include <stdio.h>

One of the simplest functions to use from <stdio.h> is printf(); which prints to stdout.

#include <stdio.h>

int main(int argc, char* argv[]) {

 int num = 1;

 printf("%d\n", num);

 return 0;

}

C has if, else if, and else which serve as control-flow statements.

#include <stdio.h>

int main(int argc, char* argv[]) {

 int age = 18;

 if (age >= 18) {

  printf("%d\n", age);

 } else {

  printf("You can't access to X resources.\n");

 }

 return 0;

}

fabsf from the <math.h> library provides safe comparisons between floats.

#include <stdio.h>

#include <math.h>

int main(int argc, char* argv[]) {

 float num = 10.4f;

 float eps = 0.0001;

 if (fabsf(num - 10.4f) < eps) {

  printf("%f\n", num);

 } else {

  printf("Insufficient resources\n");

 }

 return 0;

}

fabs from the <math.h> library provides the absolute value of a number. Often it is used with an epsilon to execute safe comparison between floating-point numbers.

#include <stdio.h>

#include <math.h>

int main(int argc, char* argv[]) {

 double num = 10.4;

 double eps = 0.0001;

 if (fabs(num - 10.4) < eps) {

  printf("%f\n", num);

 } else {

  printf("Insufficient resources.\n");

 }

 return 0;

}
